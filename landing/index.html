Out to the drive, and back

Export

  1. The API hands over every memory.
  2. Fernet encrypts them from your password.
  3. Timestamped files land on the drive.

Restore

  1. The latest export is found.
  2. It is decrypted to JSON.
  3. Any running instance ingests it.
